# Tetes (air & lingkungan)

Tetes air biru, mata titik, pipi merona, gelembung kecil, kaki tipis.

Dibuat dari `reference.png`, potongan `../tako_supporting_sheet.png`. File di folder ini hasil ekspor; sumbernya `src/characters/cast/characters/tetes.tsx`. Jangan sunting manual, jalankan `npm run cast:export`.

## File
- `tetes_master.svg`: karakter lengkap, ekspresi Senang.
- `parts/`: bagian terpisah dengan viewBox 800x800 yang sama.
- `rig_manifest.json`: palet, urutan lapisan, pivot, spesifikasi wajah.
- `expressions.png`: 10 ekspresi.

## Beda dari referensi
- Lengan tipis ditambahkan (referensi tanpa lengan).
