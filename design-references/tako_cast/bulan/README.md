# Bulan (bumi & antariksa)

Bulan purnama krem dengan kawah, topi tidur biru berpompom, pipi merona, lengan dan kaki tipis.

Dibuat dari `reference.png`, potongan `../tako_supporting_sheet.png`. File di folder ini hasil ekspor; sumbernya `src/characters/cast/characters/bulan.tsx`. Jangan sunting manual, jalankan `npm run cast:export`.

## File
- `bulan_master.svg`: karakter lengkap, ekspresi Senang.
- `parts/`: bagian terpisah dengan viewBox 800x800 yang sama.
- `rig_manifest.json`: palet, urutan lapisan, pivot, spesifikasi wajah.
- `expressions.png`: 10 ekspresi.

## Beda dari referensi
- Topi tidur ditambahkan agar mudah dibedakan dari Bumi dan Matahari.
