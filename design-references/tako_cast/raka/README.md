# Raka (sejarah)

Penjelajah kuning bertopi lapangan, badan seperti Tako dengan lengan mitten dan kaki pendek.

Dibuat dari `reference.png`, potongan `../tako_supporting_sheet.png`. File di folder ini hasil ekspor; sumbernya `src/characters/cast/characters/raka.tsx`. Jangan sunting manual, jalankan `npm run cast:export`.

## File
- `raka_master.svg`: karakter lengkap, ekspresi Senang.
- `parts/`: bagian terpisah dengan viewBox 800x800 yang sama.
- `rig_manifest.json`: palet, urutan lapisan, pivot, spesifikasi wajah.
- `expressions.png`: 10 ekspresi.

## Beda dari referensi
- Bintik gelap di tangan referensi dihilangkan (tidak jelas maknanya).
- Topi dibuat lurus, tidak miring, agar wajah frontal.
