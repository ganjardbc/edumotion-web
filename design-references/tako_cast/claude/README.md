# Claude (teknologi (AI))

Balok oranye bermata persegi panjang gelap, dua lengan balok kecil, empat kaki tipis; mengikuti maskot Claude Code.

Dibuat dari `reference.png`, potongan `../tako_supporting_sheet.png`. File di folder ini hasil ekspor; sumbernya `src/characters/cast/characters/claude.tsx`. Jangan sunting manual, jalankan `npm run cast:export`.

## File
- `claude_master.svg`: karakter lengkap, ekspresi Senang.
- `parts/`: bagian terpisah dengan viewBox 800x800 yang sama.
- `rig_manifest.json`: palet, urutan lapisan, pivot, spesifikasi wajah.
- `expressions.png`: 10 ekspresi.

## Beda dari referensi
- Mata berupa titik lonjong agar ekspresi Tako bisa dipakai; di logo berbentuk persegi panjang.
- Kaki dipasang berpasangan per sisi supaya bisa berjalan dengan rig bersama.
