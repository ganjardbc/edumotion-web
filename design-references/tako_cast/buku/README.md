# Buku (ilmu & pengetahuan)

Buku ungu tebal dengan punggung jahitan, mata putih, kaki tipis.

Dibuat dari `reference.png`, potongan `../tako_supporting_sheet.png`. File di folder ini hasil ekspor; sumbernya `src/characters/cast/characters/buku.tsx`. Jangan sunting manual, jalankan `npm run cast:export`.

## File
- `buku_master.svg`: karakter lengkap, ekspresi Senang.
- `parts/`: bagian terpisah dengan viewBox 800x800 yang sama.
- `rig_manifest.json`: palet, urutan lapisan, pivot, spesifikasi wajah.
- `expressions.png`: 10 ekspresi.

## Beda dari referensi
- Referensi miring 3/4; dibuat lurus menghadap depan.
- Lengan tipis ditambahkan (referensi tanpa lengan).
