# Jantung (tubuh manusia)

Hati merah dengan tangkai pembuluh, tangan bulat, mata putih, kaki tipis.

Dibuat dari `reference.png`, potongan `../tako_supporting_sheet.png`. File di folder ini hasil ekspor; sumbernya `src/characters/cast/characters/jantung.tsx`. Jangan sunting manual, jalankan `npm run cast:export`.

## File
- `jantung_master.svg`: karakter lengkap, ekspresi Senang.
- `parts/`: bagian terpisah dengan viewBox 800x800 yang sama.
- `rig_manifest.json`: palet, urutan lapisan, pivot, spesifikasi wajah.
- `expressions.png`: 10 ekspresi.

## Beda dari referensi
- Sarung tinju referensi diganti lengan tipis dengan telapak bulat, sepasang agar simetris.
