# Atom (sains dasar)

Inti tosca bermata bulat dikelilingi tiga lintasan ungu dengan elektron kuning, lengan dan kaki tipis.

Dibuat dari `reference.png`, potongan `../tako_supporting_sheet.png`. File di folder ini hasil ekspor; sumbernya `src/characters/cast/characters/atom.tsx`. Jangan sunting manual, jalankan `npm run cast:export`.

## File
- `atom_master.svg`: karakter lengkap, ekspresi Senang.
- `parts/`: bagian terpisah dengan viewBox 800x800 yang sama.
- `rig_manifest.json`: palet, urutan lapisan, pivot, spesifikasi wajah.
- `expressions.png`: 10 ekspresi.

## Beda dari referensi
- Lintasan hanya tiga dan digambar di belakang inti agar wajah tetap terbaca.
