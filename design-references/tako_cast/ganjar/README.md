# Ganjar (pembuat (pemilik akun))

Cowok berambut hitam berantakan, kaos dan celana kargo hitam, sepatu hitam-putih; mengikuti karakter Ganjar di remotion-web.

Dibuat dari `reference.png`, potongan `../tako_supporting_sheet.png`. File di folder ini hasil ekspor; sumbernya `src/characters/cast/characters/ganjar.tsx`. Jangan sunting manual, jalankan `npm run cast:export`.

## File
- `ganjar_master.svg`: karakter lengkap, ekspresi Senang.
- `parts/`: bagian terpisah dengan viewBox 800x800 yang sama.
- `rig_manifest.json`: palet, urutan lapisan, pivot, spesifikasi wajah.
- `expressions.png`: 10 ekspresi.

## Beda dari referensi
- Gaya realistis referensi disederhanakan ke 3 nada datar; kantong celana kargo dan lipatan baju dihilangkan.
- Kedua tangan menggantung (referensi: tangan di saku) agar bisa digerakkan rig bersama.
