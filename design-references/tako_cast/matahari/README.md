# Matahari (bumi & antariksa)

Bola kuning-oranye dengan dua belas sinar pendek, pipi merona, lengan dan kaki tipis.

Dibuat dari `reference.png`, potongan `../tako_supporting_sheet.png`. File di folder ini hasil ekspor; sumbernya `src/characters/cast/characters/matahari.tsx`. Jangan sunting manual, jalankan `npm run cast:export`.

## File
- `matahari_master.svg`: karakter lengkap, ekspresi Senang.
- `parts/`: bagian terpisah dengan viewBox 800x800 yang sama.
- `rig_manifest.json`: palet, urutan lapisan, pivot, spesifikasi wajah.
- `expressions.png`: 10 ekspresi.
