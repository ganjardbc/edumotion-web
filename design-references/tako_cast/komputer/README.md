# Komputer (teknologi (komputer))

Laptop biru terbuka: layar terang jadi wajah, kamera di tengah atas, alas lebar, lengan dan kaki tipis.

Dibuat dari `reference.png`, potongan `../tako_supporting_sheet.png`. File di folder ini hasil ekspor; sumbernya `src/characters/cast/characters/komputer.tsx`. Jangan sunting manual, jalankan `npm run cast:export`.

## File
- `komputer_master.svg`: karakter lengkap, ekspresi Senang.
- `parts/`: bagian terpisah dengan viewBox 800x800 yang sama.
- `rig_manifest.json`: palet, urutan lapisan, pivot, spesifikasi wajah.
- `expressions.png`: 10 ekspresi.

## Beda dari referensi
- Papan ketik tidak digambar; alas dibuat polos agar tidak ramai.
