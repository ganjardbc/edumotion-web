# Bumi (planet & tata surya)

Planet biru dengan benua hijau, kaki tipis.

Dibuat dari `reference.png`, potongan `../tako_supporting_sheet.png`. File di folder ini hasil ekspor; sumbernya `src/characters/cast/characters/bumi.tsx`. Jangan sunting manual, jalankan `npm run cast:export`.

## File
- `bumi_master.svg`: karakter lengkap, ekspresi Senang.
- `parts/`: bagian terpisah dengan viewBox 800x800 yang sama.
- `rig_manifest.json`: palet, urutan lapisan, pivot, spesifikasi wajah.
- `expressions.png`: 10 ekspresi.

## Beda dari referensi
- Lengan tipis ditambahkan (referensi tanpa lengan).
- Cincin dan antena referensi dihilangkan atas permintaan.
- Benua tidak mengisi area wajah; garis pantai referensi disederhanakan.
